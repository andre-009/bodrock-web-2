# ADR 0004 — BDL editorial type scale

Status: Accepted for the requested homepage implementation.

BDL 1.0 specifies a responsive editorial type scale but the foundation did not yet contain the display, section, card and lead sizes needed to implement it. This records their initial implementation in the canonical token sheet. The values follow the approved visual direction and do not change the established brand colors, font families, radii, breakpoints or motion curves. They are shared across sections, not page-specific overrides. Future design-language changes remain subject to the existing approval process.
